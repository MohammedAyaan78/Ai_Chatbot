How NeuralChat Understands You

A multi-stage Natural Language Processing pipeline running entirely client-side without external APIs.

1

Normalize

Converts input to lowercase, maps common abbreviations and slang, and strips irrelevant punctuation.

"What IS NLP???" → "what is nlp"
2

Tokenize & Stem

Splits raw text into tokens, strips 100+ stop-words, and applies 22 suffix reduction rules to extract root terms.

["chatting", "quickly"] → ["chat", "quick"]
3

Score Relevance

Blends TF-IDF vector cosine angle (40%), Jaccard keyword overlap (40%), and Levenshtein edit distance (20%).

cos(θ) = (A·B)/(|A|×|B|)
4

Contextual Reply

Selects best intent variant, updates session memory (user name, math expressions), and renders response with follow-up chips.

Intent: what_is_nlp (92% match)
